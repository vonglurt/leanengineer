Notes:
(a) Dates are ISO 8601 (YYYY-MM-DD), so folders and files sort in date
    order.
(b) nn is two digits, zero-padded (01, 02, ...); nnn is three.
(c) File name = <Document ID>[_<SHORT_TITLE>].txt, using only A-Z, a-z,
    0-9, hyphen, underscore, and period.
(d) IEEE labels and file indices differ by design: TABLE I is file T01,
    Fig. 1 is file F01.
(e) A video frame is stored locally as 99_LOCAL/frames/<video
    id>_t<seconds>.png and is published only as its ASCII descriptor, a
    figure file (DEC-00, R-04).
